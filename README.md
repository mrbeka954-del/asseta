# АССЕТА — Password Manager

## Запуск
1. Распакуй ZIP и открой папку в VS Code.
2. Запусти `index.html` через расширение Live Server (localhost).
3. Выбери «Создать хранилище» и придумай мастер-пароль минимум из 10 символов.

## Возможности
- Регистрация локального хранилища и вход по мастер-паролю.
- Шифрование записей AES-GCM; ключ выводится через PBKDF2.
- Личный кабинет, поиск, добавление, редактирование, копирование и удаление записей.
- Генератор паролей, категории, статистика и экспорт зашифрованной резервной копии.

## Важно
Это локальный учебный прототип, а не многопользовательский сервис: данные хранятся в браузере этого устройства и не синхронизируются между устройствами. Если очистить данные сайта, хранилище будет удалено. Мастер-пароль не сохраняется, восстановить записи без него невозможно. Сохраняй резервную копию в безопасном месте. Для публичного запуска нужен backend, HTTPS, аудит безопасности и тестирование.
